# Фотопринт Контур — единая система управления (хакатон Фотопринт, трек 1 + каркас треков 2/3)

**Платформа «Пульс»** — управленческий контур компании Фотопринт: три контура (аналитика «Пульс», рабочие места «Цех», «Люди и деньги»), замкнутая петля «сигнал → причина → решение → проверка эффекта», AI-ассистент «Проявитель» с подтверждением действий, единые роли и аудит.

> Полные документы: `../00_КОНЦЕПЦИЯ.md`, `../01_АРХИТЕКТУРА.md`, `../02_МОДУЛИ.md` (в папке проекта хакатона).

## Запуск

### Вариант А — docker compose (машина жюри)

```bash
cp .env.example .env          # при необходимости поправить секреты
docker compose up --build
# web:  http://localhost:5173
# api:  http://localhost:8080/swagger
```

### Вариант Б — локально (разработка)

Требуется: .NET 9 SDK, Node 24+, MySQL 8 на localhost:3306.
Строка подключения берётся из `api/src/Kontur.Api/appsettings.Development.json`
(файл с реальным паролем в git не попадает; шаблон — в `appsettings.json`).
База `kontur` и схема создаются автоматически при первом старте.

```bash
# 1. API (миграции/сид/датасет применяются при старте)
cd api && dotnet run --project src/Kontur.Api       # http://localhost:8080/swagger

# 2. Web
cd web && npm i && npm run dev                       # http://localhost:5173

# 3. Синтетика (при необходимости перегенерировать)
python dataset/generate.py
```

## Переменные окружения

См. `.env.example`. Секреты в репозиторий не коммитятся (ОТ-03): в `.env.example` только заглушки.

## Известные ограничения (честно)

- Все данные синтетические; генератор и допущения — `dataset/README.md`.
- Интеграции CRM/ERP/1С/календарь/почта — реалистичные моки за адаптерами (`ISourceAdapter`); подмена на реальные API не меняет контракт.
- Финансовые суммы — условные единицы (демо-масштаб), без абсолютных значений (требование ТЗ).
- Оплата, публикация в сторах, ЭДО — вне объёма (ТЗ §2).
