# Синтетический датасет платформы «Пульс»

Все данные **вымышленные** (ОТ-03), генерируются детерминированно (`random.seed(42)`),
даты относительны к текущему дню — датасет всегда «свежий» для демо.

Регенерация: `python dataset/generate.py` (пишет в `dataset/seed/`).

## Состав и соответствие ТЗ §8

| Файл | Строки | Требование ТЗ |
|---|---|---|
| `orders.csv` | ~1800 | заказы ≥ 500 (клиент, продукт, сумма, канал, статусы, сроки) |
| `order_events.csv` | ~14000 | трекинг этапов (источник KPI lead time / в срок) |
| `defects.csv` | ~46 | брак: станок, смена, причина, кем найден |
| `customers.csv` | 252 | клиенты ≥ 200 (+ 5 пар дублей для сюжета качества данных) |
| `interactions.csv` | 352 | обращения ≥ 300 (тема, канал, SLA, результат) |

| `budget_lines.csv` | 78 | финансовый факт по статьям (units, без абсолютных сумм) |
| `products.csv` | 6 | каталог picPac ≥ 5 (цены, требования к фото, сроки) |

## Встроенные сюжеты (для drill-down и демо)

| Код | Сюжет | Как увидеть |
|---|---|---|
| S1 | Сезонность ×1.6–2.2 (Новый год, 8 марта, выпускные, свадьбы) | графики оборота за 2 года |
| S2 | «Станок №3»: брак ~9% последние 14 дней (норма 2%), причина equipment | drill-down KPI брака → станок |
| S3 | «CDEK-инцидент»: неделя 15–21 день назад — SLA 47%, вал «доставки» | drill-down SLA → неделя → тема |
| S4 | Разгон спроса к Новому году: дефицит мощности на горизонте 4 недель | прогноз demand-vs-capacity |
| S5 | Грязные данные: 5 дублей клиентов, CRM отстаёт 8 ч, 1С расходится 0.7% | экран качества данных |
| S6 | **Яд в базе знаний**: `doc-18` содержит prompt-injection (специально) | демо защиты ассистента (ТЗ §7.4) |

## Допущения (документируем честно)

- История заказов — 2 года, ~2.1 заказа/день базового спроса, рост ~0.5%/мес.
- Цены/суммы — BYN; бюджетные статьи — условные единицы (масштаб скрыт).
- Смена 8 часов, 6 линий производства; отсутствия ~5.5% ближайшего месяца.
- SLA-нормативы поддержки: доставка 4 ч, образцы/брак 2 ч, ошибка клиента 3 ч.
- Расшифровки встреч написаны вручную под сценарии ТЗ трека 3 (80%+ явно
  сформулированных задач, есть пункты «требует уточнения» и задача без владельца).
- Все ФИО сгенерированы из пула популярных имён, совпадения случайны.
